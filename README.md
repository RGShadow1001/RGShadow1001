To bridge AI with the physical world, I deployed the ESP32-S3 (N16R8).

  - The Debugging Journey: I faced major roadblocks with Windows Store App
    Control blocking my compiler. Through collaborative debugging, I bypassed

  - Custom Kernel: I wrote a specialized WiFi Engine that:

      - Visualizes network traffic with a Synced 3-Blink Green Flash on the RGB
